# Personal Website

A personal website designed to represent different aspects of my life, interests, work, and learning journey in one place.

This repository currently contains files from an older version of my personal website. It will eventually be rebuilt into a more comprehensive website that goes beyond a conventional developer portfolio.

## Vision

The idea is to create a single place that represents **me as a person**, rather than focusing only on my professional or technical work.

The website will bring together different parts of my life, including academics, programming, projects, creative work, hobbies, interests, achievements, and personal growth.

Some information may be maintained directly on the website, while information that already exists on other platforms may eventually be retrieved automatically.

For example:

```text
GitHub
   ↓
Programming & Projects

LeetCode
   ↓
DSA & Problem Solving

Writing Platforms
   ↓
Articles & Writing

Other Platforms
   ↓
Relevant Activities

Personal Data
   ↓
Education, Skills, Interests, etc.
```

The website is intended to become a central representation of my journey across these different areas.

## Planned Sections

The exact structure has not been finalized, but the website may include sections such as:

### About

A general introduction and overview of who I am.

### Journey

A timeline or collection of important stages, experiences, and milestones.

### Academics

Information related to my education, courses, academic work, and learning progress.

### Programming

Programming languages, technologies, projects, and other technical work.

### Projects

A collection of projects, including their descriptions, technologies, repositories, and live versions where available.

### Writing

Articles, essays, poetry, and other written work.

### Creative Work

A place for creative work such as drawing, design, photography, or other forms of creative expression.

### Hobbies & Interests

Different interests and activities outside academics and programming.

### Achievements

Achievements, certificates, competitions, internships, programs, and other milestones.

### Activity

Where possible, activity from external platforms may be displayed automatically.

For example:

```text
GitHub
├── Repositories
├── Contributions
└── Activity

LeetCode
├── Problems solved
├── Difficulty statistics
└── Contest information
```

## External Data

One of the longer-term goals is to connect the website with platforms where information about my work already exists.

Possible sources include:

* GitHub
* LeetCode
* Writing platforms
* Other relevant platforms

The purpose is not to connect every possible platform, but to use external data where it makes the website more useful and reduces unnecessary manual updates.

The availability of APIs and other data-access methods will determine which platforms can actually be integrated.

## Planned Architecture

The website may eventually use a structure similar to:

```text
External Platforms
        │
        ├── GitHub
        ├── LeetCode
        ├── Writing Platforms
        └── Other Sources
                │
                ▼
         Data Collection
                │
                ▼
       Backend / Processing
                │
                ▼
       Database / Cache
                │
                ▼
            Website
```

However, the architecture and technology stack have not been finalized.

The implementation will be decided after learning the technologies required to build the project properly.

## Technology

The final technology stack is currently undecided.

Technologies that may be explored during development include:

* HTML
* CSS
* JavaScript
* React or another frontend framework
* Python
* Flask or FastAPI
* REST APIs
* PostgreSQL or another database
* Git and GitHub

The goal is to choose technologies based on the actual requirements of the website rather than deciding on the entire stack beforehand.

## Development Approach

The website will be developed gradually.

The initial version will focus on creating the core website and establishing its structure.

Later versions can introduce more advanced features such as:

```text
Basic Website
      ↓
Interactive Website
      ↓
External Data Integration
      ↓
Backend
      ↓
Database / Caching
      ↓
Automated Updates
```

This approach allows the project to grow alongside my understanding of the technologies involved.
